# Presets

This folder holds layer presets shared from AbsentMotion. Each subfolder (`presets/<name>/`) holds one preset: `<name>.absproj` (a preset bundle, at most 20 MB) and `item.json` (its details). Older presets are a `<name>.xml` file instead (a `<scene>` file with one layer, at most 1 MB).

A preset bundle is shared from the app with **Home > Templates > My Presets**, the preset's menu, and **Share to Community**. It holds the one preset layer on its placeholder picture or video, packed in the bundle.

A preset has no picture file: the app draws the preset itself on its placeholder and shows its most visible moment, so the picture always matches the preset.
