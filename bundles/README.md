# Bundles

This folder holds Community bundles exported from AbsentMotion. Each subfolder (`bundles/<name>/`) holds one bundle: `<name>.absproj` (at most 20 MB), `thumb.webp` (its picture), and `item.json` (its details).

The picture is a frame of the bundle's own project, chosen by the creator when exporting the Community bundle. `scripts/community.py add` copies it out of the bundle; never replace it with another image.
